## 개요
3·4주차 사례연구 부지(여의도 48-1·48-5, 이태원 124-3·124-4)를 교수님 A15 엔진
(월별 CF · Equity IRR · Bisection Goal Seek · 5×5 민감도)으로 재평가하고 자본배분을 결정합니다.

## A15+ 확장 기능
- 공사비 = 용도 기준단가(오피스텔 800 · 호텔 1,040) × 부지 할증계수(지하·굴토)
- UseMix: 용도 대안별 최대 매입가 비교 → 최유효이용(HBU) 정량 검증
- 수입 3유형(분양 · 임대 Cap · 호텔 Cap), 준공 후 안정화, S-Curve, 분할분양
- 몬테카를로 1,000회(시드 고정) → 목표 IRR 달성확률 · 80% 안전 매입가
